This repo documents the **RTL Design and Synthesis Kickstart**, covering everything from fundamental Verilog simulation and synthesis to optimization techniques using open-source EDA tools.

### 🌟 Key Learnings from Week 1
-   Simulated Verilog designs using **Icarus Verilog** and visualized with **GTKWave**.
-   Synthesized RTL code into gate-level netlists with **Yosys**.
-   Analyzed timing libraries and different synthesis approaches.
-   Learned best practices for coding combinational and sequential logic.
-   Explored advanced synthesis topics and optimization strategies.
